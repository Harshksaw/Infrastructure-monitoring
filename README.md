# Infrastructure Monitoring

Lightweight self-hosted monitoring for one main VPS plus additional VPS agents.

## Final setup

### Main VPS

- Your existing apps
- Nginx or Caddy reverse proxy
- Beszel Hub at `monitor.yourdomain.com`
- Uptime Kuma at `uptime.yourdomain.com`
- Beszel Agent to monitor the main VPS itself

### Other VPSs

- Beszel Agent only

This setup keeps things simple:

- **Beszel** for host and Docker stats, historical data, and alerts
- **Uptime Kuma** for website/API uptime and SSL checks
- **Telegram or Discord** for notifications

Skip Grafana/Loki until you actually need centralized log search.

## Repository structure

```text
infra-monitoring/
├── docker-compose.main.yml
├── docker-compose.agent.yml
├── nginx-monitoring.conf
└── README.md
```

## Main VPS deployment

Use `/home/<user>/infra-monitoring` or another deployment directory on the main VPS.

```bash
mkdir -p ~/infra-monitoring/data/beszel ~/infra-monitoring/data/uptime-kuma
cd ~/infra-monitoring
cp /path/to/repo/docker-compose.main.yml .
docker compose -f docker-compose.main.yml up -d
```

`docker-compose.main.yml` starts:

- Beszel Hub on `127.0.0.1:8090`
- Uptime Kuma on `127.0.0.1:3001`

Both services are bound to localhost so they can sit behind your reverse proxy.

## Reverse proxy

Use `nginx-monitoring.conf` as a starting point and replace:

- `monitor.yourdomain.com`
- `uptime.yourdomain.com`

Then enable SSL:

```bash
sudo certbot --nginx -d monitor.yourdomain.com -d uptime.yourdomain.com
```

## Beszel agent setup

Do **not** manually invent the Beszel agent token or key.

1. Open `https://monitor.yourdomain.com`
2. Go to **Add System**
3. Copy the Docker Compose agent config generated by the Beszel Hub UI
4. Replace the placeholder values in `docker-compose.agent.yml` on each VPS
5. Start the agent with Docker Compose on that VPS

Example:

```bash
mkdir -p ~/infra-monitoring
cd ~/infra-monitoring
cp /path/to/repo/docker-compose.agent.yml .
docker compose -f docker-compose.agent.yml up -d
```

## Uptime Kuma monitors to add

Add monitors for:

- `https://your-prod-app.com`
- `https://api.your-prod-app.com/health`
- `https://admin.your-prod-app.com`
- SSL certificate expiry
- Ping checks for each VPS IP

Set alerts to Telegram or Discord.
